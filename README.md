# Mulearn Redesign Task

A redesigned version of the KTU (Kerala Technological University) student portal, rebuilt with a cleaner interface and extra functionalities to make it more student-friendly and easy to use.

🔗 **Live Demo:** [rad-alfajores-9d3a66.netlify.app](https://rad-alfajores-9d3a66.netlify.app/)

## About

The original KTU student portal can feel cluttered and hard to navigate. This project reimagines the experience with a modern, simplified UI while keeping all the core functionality students rely on daily — dashboard, courses, attendance, assignments, results, timetable, and fee details.

## Features

- **Dashboard** – A quick overview of the student's academic status at a glance
- **Courses** – Browse enrolled courses in a clean, organized layout
- **Attendance** – View attendance records without digging through clunky menus
- **Assignments** – Track pending and submitted assignments
- **Results** – Check semester results in an easy-to-read format
- **Timetable** – View the class schedule clearly
- **Fees** – Check fee status and payment details

## Tech Stack

- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Interactivity and dynamic behavior
